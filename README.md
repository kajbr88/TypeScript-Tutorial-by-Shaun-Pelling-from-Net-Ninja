# TypeScript Tutorial by The Net Ninja (Shaun Pelling)

This repository contains the code and notes from the TypeScript Tutorial series by Shaun Pelling (The Net Ninja) on YouTube.

## About the Tutorial

This tutorial covers the fundamentals of TypeScript, a superset of JavaScript that adds static typing to the language with a Finance Logger Project. It's designed for beginners and developers looking to enhance their JavaScript skills with type safety and improved tooling.

The series typically covers topics such as:

* Introduction to TypeScript and its benefits
* Setting up the development environment
* Basic types (number, string, boolean, etc.)
* Type inference
* Arrays and Tuples
* Objects and Interfaces
* Functions and Function types
* Classes and Inheritance
* Generics
* Enums
* Type Aliases
* Working with the DOM in TypeScript
* Modules
* Configuration with `tsconfig.json`
* And more...

## Repository Structure

This repository is organized to mirror the structure of the tutorial. You will likely find folders or files corresponding to the different sections or lessons within the series.

## How to Use This Repository

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/kajbr88/TypeScript-Tutorial-by-Shaun-Pelling-from-Net-Ninja.git
    ```
2.  **Install Typescript :**
    * Typescript requires NodeJS installed in the system to install and copile Typescript,So go ahead and install NodeJS first.

    * Then to install Typescript Compiler globally type in the following command in the Terminal or Command Prompt/Powershell.   
    ```bash
    npm install -g typescript
    ```
3.  **Navigate to the relevant section:**
    Browse the folders to find the code examples related to specific topics covered in the tutorial.
    
5.  **Run the code:**
    Follow the instructions within the specific folder or the tutorial videos to execute the TypeScript code (usually involves compiling to JavaScript and then running the JavaScript file). For example:
    ```bash
    tsc <typescript-file>.ts  # Compile TypeScript to JavaScript
    node <javascript-file>.js # Run the JavaScript file
    ```
